# BS 塞尔达传说 广播推送终端 (BS-Zelda-Satellaview-Terminal)

本项目是一个为 **汉化版 BS 塞尔达传说 (BS Zelda no Densetsu)** 设计的第三方辅助工具。它旨在模拟 1995 年原版 Satellaview 的实时同步广播音频流。并且通过 Python 与 Mesen 模拟器联动，还原当年的剧情播放与成绩结算系统。

本项目与目前现有利用 MSU-1 重建的 BS Zelda 改版作品不同。因卫星广播数据下发在 PSRAM 中的代码近乎永久性物理丢失，利用 MSU-1 补丁 + 音视频资源只能将目前存在的 DumpROM 重建为一部“看起来很相似”的独立游戏。而利用本项目的功能，可以近乎于重建当年 Satellaview 的完整逻辑和体验。如果说 MSU-1 改版是补完了游戏部分的缺失，那本项目能做到的事情就是带你真正的回到 1995 年的那个晚上。

## 🛠️ 核心功能
* **自动修改配置**：开启程序后可自动完成模拟器 BS-X 部分的相关配置。
* **虚拟卫星推送**：模拟 18:00 广播开始后，自动触发数据下发。
* **视频遮罩投影**：使用 mpv 核心播放剧情视频，模拟重构丢失的 PSRAM 部分程序。
* **音频同步管理**：支持播放外部 `.wav` 广播音频，并具备检测加农战触发后的静音逻辑。
* **实时数据监视**：通过 Lua 脚本实时读取模拟器内存，监控玩家的损失总血量、死亡次数及三角力量收集进度。
* **成绩结算画面**：在游戏结束后，自动弹出成绩单遮罩，展示本周的详细战绩。

### ⚙️ 配置与启动

1. **配置模拟器**：
   * 下载 Mesen 2.1.1。
   * 双击打开并进行安装配置，必须选择 Store the data in same folder as the application，**请勿使用任何带有中文的文件夹。**
   * 关闭模拟器。
   * 下载配套使用的汉化资源包。将 `bszelda` 文件夹放置在 Mesen 模拟器的根目录中。

2. **启动程序**：
   * 运行 `main.py` 或 `Satellaview-Terminal.exe` （无需启动 Mesen 模拟器）。
   * 在界面中点击按钮选择你的 `Mesen.exe` 主程序。
   * 首次运行会要求选择 `BS-X BIOS` 文件，选择自己下载的文件即可。
   * 选择对应周任务后点击启动，模拟器会自动打开并加载对应数据。
   * 在卫星时钟到达 18：00 之后会自动推送广播数据，此时去左侧的活动中心下载游玩即可。
   * 在结局视频播放完毕之后，会自动返回模拟器画面，此时点击程序的重置按钮后，再次选择第二周开始游戏即可。

3. **注意事项**：
   * **请勿使用任何含有中文的文件夹。**
   * 要实现近乎于原版广播的体验，就请严格按照每周任务的流程进行游戏，不可随意关闭模拟器和程序，否则可能会出现存档数据读取错误。
   * 请勿在运行时关闭 Lua 脚本窗口，或在不理解用途时修改 Lua 脚本数据导致运行出错。
   * 因存档数据会一直保持在 Mesen 模拟器中，故并非必须一次性打完四周的游戏。在完成本周的游戏后，即可关闭程序和模拟器，随时进行下周的游戏，但请注意在期间不要游玩其他的BS游戏，有一定可能会覆盖存档。
   * 如遇到存档问题，可在关闭模拟器的状态下，选择 `删除存档` 按钮进行存档清空，但会清空全部BS有关的存档，请酌情使用。

5. **复原中存在的推测逻辑**：
   * 因 PSRAM 中的代码近乎于物理性丢失，故本项目中有些运行逻辑是基于当年玩家的视频资料，以及口述讲解进行制作。如将来有新史料出现，可能会进行对应的修改：
   * 1.如果玩家晚进入游戏几分钟，会无法观看到开场剧情的播出，只有等待画面。
   * 2.如果玩家迟到太久，则会直接进入游戏。
     
6. **已知未复原或无必要复原的逻辑**：
   * 从活动中心下载文件的提示。
   * 广播推送数据时的季节切换为个人设置而非官方设置，方便玩家知晓变化。
   * 在开场剧情中显示的玩家名称。
   * 在结局画面 UI 中的抽奖提示，以及抽奖密码的生成逻辑和对应程序。

### 📂 项目结构说明

* **`main.py`**：基于 Tkinter 和 OpenCV 构建的主逻辑程序，负责 UI 和视频渲染。
* **`bs.lua`**：负责内存读取与信号下发的 Lua 核心脚本，需在模拟器内运行。
* **`ui/`**：存放结算界面背景 `bg_result.png` 和三角力量动画 `triforce_on.gif`。
* **`requirements.txt`**：记录项目所需的 `pygame`, `opencv-python`, `pygetwindow` 等核心依赖。

### ❓ 常见问题 (FAQ)

* **打开程序没反应，无法打开程序，打开程序报错找不到 mpv 相关 dll**
  * 请勿使用任何含有中文的文件夹。
  * 因 `mpv-1.dll` （视频播放核心）体积较大，杀软通常会查杀几秒，稍等后再次尝试即可。
  * 如依然报错，请确认杀软放行，或将 `_internal` 文件夹中的 `mpv-1.dll` 复制到程序根目录一份再重试。
  * 非 Win10/11 系统不支持新版 mpv 核心，可自行将 `mpv-1.dll` 替换为老版本，但不保证可以正常运行。

* **游戏开始推送广播数据，或结束时复原广播数据后模拟器画面卡住**
  * 小概率会出现，请重启程序和模拟器重新进行操作即可。如当前准备继续选择下一周的游戏，则可完全无视问题直接重置并使用即可。

* **在中途突然结束模拟器和程序后，存档的计数问题**
  * 此时模拟器存档依然存在，只不过是不完整的存档，可以读取但会丢失部分计数，虽可以正常运行，但推荐不要这样做。
    
* **发现某些广播进度不同步**
  * 查看模拟器的 BS-X 时钟设置，选择 Use custom date and time，并将时间设置为 9：59，切记在选择后点击√才会生效。
  * 电脑配置过低，会导致模拟器运行缓慢丢帧，导致进度不同步，请确认电脑配置足以满帧运行 Mesen 模拟器。

* **模拟器无法与外部程序通信**
  * 请勿使用任何含有中文的文件夹。
  * 请确认程序是否被杀毒软件阻拦。
  * 请尝试使用管理员权限运行本程序。 
  * 请确认 Mesen 已经成功加载并运行了 `bs.lua` 脚本。
  * 检查模拟器目录下的 `LuaScriptData/bs` 文件夹是否具有写入权限。
  * 检查是否在模拟器内已开启 Allow access to I/O and OS functions。
    
* **UI部分显示不全或错乱**
  * 建议将 Windows 缩放比例调整为 150% 或更低即可正常使用。
